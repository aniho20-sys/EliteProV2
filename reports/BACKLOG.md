### 點解係呢個唔係 FB

`marketing-report-2026-07-24`：**50%+ 獨立教練話首要客源係口碑轉介**，社交媒體第二。你自己係教練 —— 你嘅同行網絡就係最高轉化嘅渠道，而且零成本、唔使等任何 gate。

FB 你 2026-09-08 已經否決（見 ⚫ 區），唔會再排。

### 第一步（實際動作）

1. 開 WhatsApp
2. 喺搜尋打你 gym 名，或者揭聯絡人
3. **揀 3 個你真係識、而且係做緊私教嘅人**
   - 唔使揀最熟嗰個（最熟反而最難開口）
   - 揀你知佢有固定學生、而且會嫌記數煩嗰啲
4. 逐個貼下面段文字（唔好 broadcast，一眼睇得出）

### 📋 文案（copy 就用得）

**版本 A — 普通同行**

```
喂〔名〕，有件事想問你意見。

我自己整咗個 app 幫自己記學生堂數，因為之前用 Excel
成日對唔到數，尤其係取消同補堂。而家我自己 9 個學生
都用緊。

想搵幾個教練朋友試下，睇下係咪淨係啱我自己用。

唔使畀錢，我親自幫你 set，你有幾多學生都得。
你有冇興趣試下？
```

**版本 B — 熟朋友（直接啲）**

```
〔名〕，幫我一個忙。

我整咗個管學生堂數嘅 app，自己用緊幾個月。想有人
幫我試下同畀意見 —— 你係我信得過會講真話嗰個。

十分鐘 set 好，我陪你做。試完覺得唔好用就直接講，
唔使畀面。
```

**版本 C — 問學生轉介**（你 9 個學生入面，如果有人自己都做教練或者識教練）

```
〔名〕，問你一件事 —— 你識唔識其他私人教練？

我整緊個幫教練記堂數嘅 app，想搵多幾個教練試下。
如果你識邊個，可唔可以幫我問下佢有冇興趣？
```

### 🚧 你最大機會撞到嘅障礙

| 佢會講 | 你點覆 |
|---|---|
| **「幾錢？」** | `而家唔收錢。我仲喺搵人試緊嘅階段，頭幾個教練我打算永久免費。之後都係月費制，唔會抽你學生錢嗰成。` |
| **「有幾多人用緊？」** | ⚠️ **唔好吹。** 照答：`得我自己，9 個學生。你會係第一個外部教練 —— 所以我先想搵人試,唔想自己一個人估。` |
| **「我而家用 WhatsApp / Excel 都 OK 喎」** | `我之前都係。頂唔順嘅位係學生取消同補堂 —— 你要記返佢仲剩幾多堂,遲早對唔到數。你有冇試過同學生為咗剩幾多堂拗過？` |
| **佢覆「得閒睇下」然後冇下文** | **唔好追第二次。** 隔一星期貼：`上次講嗰個 app,我加咗〔某個新功能〕。你得閒就試下,唔得就算,唔好覺得有壓力。` 再冇覆就放低,轉去下一個。 |
| **你自己開唔到口** | 呢個係真障礙,唔係藉口。**由版本 C（問學生）開始** —— 問學生識唔識人,比直接推銷畀同行容易講好多。 |

### ✅ 點先算做完

三個人**已發出訊息**（唔係「打算發」）。有冇人覆唔重要 —— 呢一步嘅完成標準係你撳咗 send。
