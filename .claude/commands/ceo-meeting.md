description: Run the weekly CEO team meeting per CLAUDE.md (app review + growth + action list)
---

主持「CEO 週例會」。請先閱讀 `CLAUDE.md` 嘅「Team Structure」同「Working Rules」段落，然後嚴格跟住入面「CEO 週例會（每逢星期四自動觸發）」嘅格式進行：

1. **開會前做功課** — 用 `git log`/`git diff` 睇返 `claude/fitness-app-features-LbxtG` 呢個星期實際做咗咩改動（commits、改咗邊啲功能、修咗咩 bug），等討論有實質根據，唔好流於空泛假設。

2. **CEO 主持，跟足以下框架同次序**：
```
[CEO] 📋 本週例會開始

【1. App 改善】
- 審視上週有咩用戶痛點未解決
- 有咩現有功能可以優化體驗
- 技術債或 Bug 需要優先處理？

【2. 用戶增長】
- 本週有咩推廣行動可以執行？
- Founding Members 進度如何？
- 有冇新嘅獲客渠道可以嘗試？

【3. 本週行動清單】
- 列出用戶今週最重要嘅 3 件事
- 每件事要有明確嘅完成標準
```

3. **各員工按職位發言**（格式：`[員工B - Dev]` / `[CEO]`），用廣東話（繁體字）討論，每位至少就議程入面同自己職位相關嘅一點俾意見（A-系統分析、B-開發、C-審核、D-UI/UX、E-QA、F-Security、X-Marketing）。

4. **主管（PM）總結** — 將「本週行動清單」整理成清晰、可執行、有完成標準嘅清單，作為呢次會議嘅最終輸出。

呢個係定期自動觸發嘅例會，唔需要等用戶確認先開始 —— 直接跟以上步驟進行並輸出完整會議記錄。
